A real clause library

Universal obligations plus trade-specific inclusions and exclusions across the CSI divisions that actually get bid — concrete, steel, envelope, fire protection, plumbing, HVAC, electrical, sitework and more.

Cross-division spec sections

A fire protection package automatically gets offered the Division 07 firestopping and Division 08 access doors it is contractually responsible for. That is where scope gaps come from.

Documents that survive review

Real paged PDFs with running headers and page numbers, selectable text, and an outline where 3.2.4 points at exactly one sentence in every format you export.

Versioned and auditable

Issuing a scope freezes an immutable revision. Later edits create a new version, so what went out with the subcontract is preserved verbatim.

API and self-hosting
